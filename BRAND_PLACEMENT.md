# Brand placement rules (M1+)

Source: `CREATIVE_BRIEF.md`. Keep marks subtle — streetwear-clean, not cluttered HUD.

## Global

- **No giant watermarks** on game HUD
- Brand mark energy belongs on **carpet / ticket stub** in the lobby and on **world objects** in-game
- Soft CTAs only after a run ends

## Court Vision (when gameplay lands)

1. Small 5D mark on **rim plate / front support**
2. Center-court mark ~15–20% opacity
3. Micro stamp on ball seam
4. Backboard = faint geometry ONLY — **NO big logo**
5. Sideline type banners; max one small mark in corner

**End doors (always):** Challenge a friend · Enter boutique

## Fifth Run (when gameplay lands)

- Logos on **world objects** (boutique windows, record-store neon, theater marquee) — not HUD watermark
- Obstacles stay anonymous (no faces)

**End doors (always):** Challenge a friend · Enter record store
