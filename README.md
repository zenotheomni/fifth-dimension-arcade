# Fifth Dimension Arcade

Mobile-web arcade for [5Dimperial](https://5dimperial.com) — **The Fifth Floor** lobby, Court Vision, Fifth Run.

**Stack:** Next.js (App Router) · TypeScript · React 19  
**Public path:** `/arcade` (Vercel + later `5Dimperial.com/arcade`)

This is a dedicated repo (`zenotheomni/fifth-dimension-arcade`). It is **not** the 5D landing page and **not** Shopify.

## M1 scope

- Lobby shell (ticket header, swipe cabinets, dock, desktop QR gate)
- Placeholder routes for Court Vision, Fifth Run, Challenge, NFC Key
- Arcade-core: identity (`getOrCreatePlayerId`), cabinet config, analytics stub (`track()` → console in dev)
- No gameplay, no real scores API, no paywalls

## Develop

```bash
npm install
npm run dev
# → http://localhost:3000/arcade
```

## Build

```bash
npm run build
npm start
# → http://localhost:3000/arcade
```

`package-lock.json` is generated by `npm install` (omitted from the M1 GitHub push because of MCP payload size). Runtime pins: `next@16.3.5`, `react@19.2.8`.

## Deploy (Vercel)

1. Import this GitHub repo into Vercel (framework: Next.js, root of repo).
2. `next.config.ts` sets `basePath: "/arcade"` so routes and `/_next` assets live under `/arcade`.
3. `vercel.json` redirects `/` → `/arcade`.
4. After deploy, the lobby is at `https://<project>.vercel.app/arcade`.

### Linking from 5Dimperial.com

`5Dimperial.com` should **link or reverse-proxy `/arcade`** to this Vercel project (not to `5D-Landing-Page` or Shopify).

If proxying, forward `/arcade` **and** `/arcade/_next/*` to this deployment so App Router assets resolve.
